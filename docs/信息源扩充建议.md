## 五、时效性升级

| 维度 | 现状 | 建议 |
|---|---|---|
| 抓取频率 | 每日 1 次（09:00） | 全量每日 1 次 + 重点源每小时增量 |
| 推送策略 | 每日 1 推 | 每日早报 + 重大事件即时推送（如 OpenAI/Anthropic 官方发布 5 分钟内） |
| 实时通道 | 无 | GitHub release 用 webhook、X 用 polling、官博用增量爬 |
| 重要度分层 | 无 | 三档：💥核弹级（即时推） / 🔥高 / 📌一般 |

**重大事件触发器**（命中即时推送）：
- 标题含 `gpt-`, `claude-`, `gemini-`, `release`, `launch`, `announce` 且来源是模型厂官方
- HN 评论数 > 200 或 评分 > 300
- GitHub Trending 一日 star > 2000

## 六、技术架构升级建议

### 1. 多协议抓取层
- 现状：只用 RSS + 少量 HTML
- 升级：RSS / HTML / API / webhook / RSSHub 自部署 五条并存
- RSSHub 自部署是核心：把所有「无 RSS」的源（X、微博、知乎、公众号、B 站、Anthropic News）统一接入

### 2. 跨源主题聚类（路线图 v0.4 兑现）
- 用 embedding 把同一新闻的多个报道聚成一组
- 报告里展示「⚡同主题 N 个媒体在报」，提升信号密度
- 适用模型：`text-embedding-3-small` 或本地 `bge-small-zh`

### 3. 报告分层渲染
```
💥 今日核弹（≤3 条，必看）
🔥 重要进展（10 条左右）
📌 行业动态（按板块展示）
🌐 实时简讯（带时间戳，最近 N 小时）
```

### 4. 双语展示
- 英文源原标题保留，下挂中文一句话摘要（已有 summarize.py 模块）
- 模型默认从 `claude-opus-4-7` 升到 `claude-haiku-4-5` 降本，重大新闻才用 Opus

### 5. 历史趋势（v0.4）
- 同一关键词（"Claude 4.7"、"Sora 2"）的日 / 周热度曲线
- 在 web/ 加趋势页：折线图 + 关联报道时间轴
